# Python Fundamentals

A structured collection of Python code examples, exercises, mini-projects and guides covering the core concepts of the language.

This repository documents my learning path in Python. The content is based on a Python course I am taking, expanded with my own explanations, extra examples and additional topics I research along the way.

---

## About

The goal of this repository is to build a solid foundation in Python by turning every concept into working code. Each topic includes:

- **Concepts**: short explanations of how and why something works
- **Examples**: commented code demonstrating the concept in practice
- **Exercises**: practice problems with my solutions
- **Projects**: small applications that combine multiple concepts

Theoretical notes and longer summaries live in a separate repository, [dev-study-log](https://github.com/<username>/dev-study-log).

## How to Run

Requirements: Python 3.10 or higher.

```bash
# Clone the repository
git clone https://github.com/<username>/python-fundamentals.git
cd python-fundamentals

# Run any example
python concepts/<topic>/<file>.py
```
